# Spy Game

A pass-the-phone party game inspired by Spyfall. Everyone secretly learns the location except the spy; ask questions, vote, find the spy before time runs out.

Originally an Angular 10 app (2020), rewritten with React, Vite, TypeScript and Tailwind CSS. See [CLAUDE.md](CLAUDE.md) for architecture and conventions.

```bash
npm install
npm run dev
npm test
npm run build
```
